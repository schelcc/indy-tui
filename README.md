# indy-tui

`indy-tui` is a TUI designed to augment the experience of watching and following the on-track events of North America's premier open-wheel series, and to do so live, delayed, or on another date altogether.

## Prototype Demo

Below is a recorded demo of an early-stage `indy-tui`. The UI will likely change, but the core demonstration of functionality is present. The telemetry presented is part of a sample session with fake names.
